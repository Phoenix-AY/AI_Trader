# AI Trading System (Intraday)

This project is an AI-powered intraday trading system built using Python.

## 🚀 Features
- Fetch real-time and historical stock data using Alpaca API
- Feature engineering using technical indicators (EMA, etc.)
- Strategy generation (EMA crossover)
- Backtesting engine with capital tracking
- Risk management (position sizing, transaction costs)
